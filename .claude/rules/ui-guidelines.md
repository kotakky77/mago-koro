# 高齢者向け UI 設計ガイドライン

本アプリは祖父母ユーザー（65歳以上を想定）が主要ターゲットの一つであるため、特に祖父母向け画面では高齢者に配慮した設計を徹底する。

## デザインシステム（孫からのおねがい帳 — 2026-09 リニューアル）

祖父母が「贈りたくなる」ことを目的に、**孫の写真・ひとこと・誕生日までの日数**を主役にする。
生成りの便箋 + 朱色 + リボンの深紅。モックは `docs/screen-design-mock/v2/`。

### カラーパレット

`src/app.css` の `:root` にCSS変数として定義済み。**色は必ず変数経由で使う**:

| 変数 | 用途 | 値 |
|------|------|------|
| `--primary` | 主要ボタン・朱（白文字で5.0:1） | `#c2452d` |
| `--primary-soft` | 淡い朱の背景 | `#fbe9e1` |
| `--secondary` | リンク・副次ボタン・紺 | `#2b4a6f` |
| `--ribbon` | 「贈る予定」のリボン（白文字で6.4:1） | `#a8323e` |
| `--accent-soft` | ガイド枠・吹き出しの淡い金茶 | `#fbf1dc` |
| `--gold` / `--gold-line` | 金茶の文字（5.5:1）/ 線・飾り専用（文字に使わない） | `#8a5a12` / `#d9b56c` |
| `--text` | 本文 | `#3b332b` |
| `--text-sub` | 補足文（これより薄い色は使わない） | `#665b4f` |
| `--bg` / `--surface` | 生成りの背景 / 便箋 | `#f7f0e4` / `#fffdf8` |
| `--danger` / `--success` | エラー / 成功・「贈った」 | `#b3261e` / `#2f6b3f` |

- テキストと背景のコントラスト比4.5:1以上を維持
- `#999` のような薄いグレー文字は禁止

### フォント

- 本文は "Noto Sans JP" + システムフォントフォールバック
- **見出し（h1〜h3・ロゴ・数字）だけ Google Fonts の "Kiwi Maru"**（`--font-heading`）。
  祖父母のPCがWindowsだと丸ゴシックが無いため読み込む。読み込めなくても本文と同じゴシックで表示される
- 行間 `1.7` / 本文 **17px**（768px以下は16px）/ 見出し **20px以上** / ボタンラベル **16px以上**

### キャッシュ

- `/app.css` と `/app.js` は1時間キャッシュされる。レイアウトは `?v=<中身のハッシュ>`
  （`src/asset-version.ts`）を付けて読むので、デプロイ直後に古いCSSで崩れることはない

### アイコン

- **絵文字**を使用（Font Awesome等の外部アイコンは使わない）
- テキストラベルと併用し、アイコンだけに意味を持たせない
- アイコンのみのボタンには `aria-label` を付与

## レイアウト原則

- カード: `.card`（便箋色の背景・角丸18px・柔らかい影・padding 24px）
- グリッド: `.card-grid` / `.photo-grid`（`auto-fill` + `minmax` でレスポンシブ）
- ブレークポイント **768px** でモバイル1カラム
- タッチターゲットは **44px×44px以上**（`.btn` は min-height 48px、`.btn-lg` は60px）

## 祖父母向け画面の設計指針

- メニューはシンプルに保つ。現在は マイページ / 写真を見る / ほしいもの / 記念品
  + ログアウト（フェーズ2で「記念品」が増えた）。これ以上は増やさない
- **ヘッダーに追加した導線はマイページのカードにも置く**。祖父母はヘッダーのリンクに
  気づきにくいため、主要機能はマイページから大きなボタン（`.btn-lg`）で辿れること
- 現在ページは `.active` クラスで明示
- 各ページに「← マイページに戻る」リンク（`.back-link`）を設置
- 主要操作は `.btn-lg`（20px / min-height 60px）
- 重要な操作（購入報告・削除）は `data-confirm` 属性で**確認ダイアログ**
  （`src/client.js` が処理）
- 各ページに操作手順のガイダンス（`.guide` + `<details>` で折りたたみ）
- 専門用語を避け、平易な日本語で記述（例:「購入したことを知らせる」）

## 写真閲覧

- グリッドは `minmax(200px, 1fr)`、写真全体が拡大ボタン（`.photo-view-btn`）
- モーダル拡大表示は `src/client.js` が制御: Escapeで閉じる・矢印キーで前後・
  背景クリックで閉じる・フォーカス戻し

## アクセシビリティ

- インタラクティブ要素に適切なARIA属性（モーダルは `role="dialog" aria-modal="true"`）
- キーボード操作: Tab移動 / Enter・Space / Escape / 矢印キー
- フォーカスインジケータを消さない（`:focus` は3pxアウトラインで統一済み）
- 画像には `alt` を設定（撮影日等の文脈を含める）

## 主要CSSクラス一覧（`src/app.css`）

| クラス | 用途 |
|--------|------|
| `.btn-primary` / `.btn-secondary` | 主要（朱）/ 副次（紺）ボタン |
| `.btn-quiet` | 控えめな操作（取り消し・ログアウト等） |
| `.countdown` / `.chip` | 誕生日までのカウントダウン（大 / 小） |
| `.letter` / `.child-hero` | 便箋（孫からの手紙）/ 孫の丸い写真 |
| `.onegai-card` (`.is-reserved` `.is-given`) | おねがいカード（リボン / ありがとうのハンコ）。部品は `src/views/onegai.tsx` |
| `.speech` | 孫の「ひとこと」（ほしいものの description）の吹き出し |
| `.child-panel` / `.stats` | マイページの孫ごとのカード / おくりもの状況の数字 |
| `.thanks-card` | 購入通知（ありがとうのお知らせ） |
| `.btn-outline` / `.btn-danger` | 枠線ボタン / 危険操作 |
| `.btn-lg` | 大きいボタン（祖父母向け主要操作） |
| `.card` / `.card-grid` | カード / カードグリッド |
| `.photo-grid` / `.photo-item` | 写真グリッド |
| `.modal` | 写真拡大モーダル |
| `.item-list` | ほしいもの・通知のリスト |
| `.tag` (`-pending` `-accepted` `-purchased` `-expired`) | ステータスタグ |
| `.form-group` / `.form-errors` / `.form-hint` | フォーム |
| `.flash` (`-notice` `-alert`) | フラッシュメッセージ |
| `.guide` | 操作ガイダンス枠（`<details>`） |
| `.back-link` | 戻るリンク |
| `.nav-badge` | 未読件数バッジ |

## 新しい画面を作るときのチェックリスト

- [ ] フォントサイズは16px以上か
- [ ] ボタンは44px以上のタッチターゲットか
- [ ] 色はCSS変数経由か・コントラストは十分か
- [ ] 操作手順の説明（`.guide`）があるか
- [ ] 破壊的・重要操作に `data-confirm` が付いているか
- [ ] モバイル表示（768px以下）で崩れないか
- [ ] キーボード操作が可能か・フォーカスが見えるか
- [ ] 既存のCSSクラスを再利用しているか（新規作成は最小限に）
