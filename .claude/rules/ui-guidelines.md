# 高齢者向け UI 設計ガイドライン

本アプリは祖父母ユーザー（65歳以上を想定）が主要ターゲットの一つであるため、特に祖父母向け画面では高齢者に配慮した設計を徹底する。

## デザインシステム

### カラーパレット

CSS カスタムプロパティとして定義済み（`application.css`）:

| 用途 | 色 | 値 |
|------|-----|------|
| プライマリ | 暖色オレンジ | `#FF9E80` |
| セカンダリ | ブルー | `#64B5F6` |
| アクセント | イエロー | `#FFD54F` |
| テキスト | ダークグレー | `#333333` |
| 背景 | ライトグレー | `#F5F5F5` |
| ボーダー | グレー | `#E0E0E0` |

- 暖色系を基調とし、親しみやすさを重視
- テキストと背景のコントラスト比を十分に確保する

### フォント

- **フォントファミリー**: "Noto Sans JP"（日本語対応、可読性が高い）
- **行間**: `line-height: 1.6`（余裕を持たせる）
- **本文**: 16px 以上
- **見出し**: 20px 以上
- **ボタンラベル**: 16px 以上

### アイコン

- **Font Awesome 5.15.4** を使用
- テキストラベルと併用し、アイコンだけに意味を持たせない

## レイアウト原則

### カードコンポーネント

```css
.dashboard-card, .card {
  background: white;
  border-radius: 8px;
  box-shadow: 0 2px 5px rgba(0, 0, 0, 0.1);
  padding: 20px;
}
```

- 角丸でやさしい印象
- 白背景 + 影で視覚的にグルーピング
- 十分な内側余白（20px 以上）

### グリッドレイアウト

```css
display: grid;
grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
gap: 15px;
```

- `auto-fill` + `minmax` でレスポンシブ対応
- 写真グリッド、商品グリッドで使用

### レスポンシブ対応

- ブレークポイント: **768px**（モバイル / デスクトップ）
- モバイルでは1カラムレイアウトに切り替え
- タブUIはモバイルでドロップダウンに変換
- タッチターゲットは **44px x 44px 以上**を確保

## 祖父母向け画面の設計指針

### 文字とコントラスト

- 本文フォントサイズは **16px を最低ライン**とし、重要な情報は 18px 以上
- 薄いグレーのテキスト（`#999` 等）は使用しない。最低でも `#666` 以上
- リンクテキストは下線または明確な色の違いで識別可能にする

### ボタン

- 十分な大きさ: パディング **12px 24px 以上**
- 大きいボタン (`btn-lg`): パディング **15px 30px**, フォント **18px**
- 明確なラベル: 「購入する」「写真を見る」等、動作が分かる文言
- ホバー・フォーカス時の視覚変化を明確に

### ナビゲーション

- 祖父母向けメニューはシンプルに（4項目以内）:
  - マイページ / ほしいものリスト / 写真閲覧 / 記念品案内
- 現在のページがどこか分かるよう、アクティブ状態を明示
- 「戻る」「ホームに戻る」リンクを各ページに設置

### 操作の安全性

- 重要な操作（購入等）は**確認ダイアログ**を表示
- 取り消し可能な操作を優先設計
- エラー時は**何が起きたか・何をすればよいか**を平易な日本語で表示

### 写真閲覧

- 写真は大きく表示（グリッドの `minmax(200px, 1fr)`）
- モーダルで拡大表示（前後ナビ、キーボード操作対応）
- スライドショー機能あり（3秒間隔）

### 説明・ガイダンス

- 各ページに操作手順や注意事項のセクションを設ける
- FAQ セクションは `<details>` 要素で折りたたみ表示
- 専門用語を避け、平易な日本語で記述

## アクセシビリティ

### ARIA 属性

インタラクティブ要素には適切な ARIA 属性を付与:

```html
<!-- タブUI の例 -->
<div role="tab" aria-selected="true" aria-controls="panel-1" tabindex="0">
<div role="tabpanel" id="panel-1" aria-hidden="false">
```

### キーボード操作

- Tab キーでフォーカス移動
- Enter / Space でボタン押下
- Escape でモーダル閉じ
- 矢印キーでタブ・スライド操作
- フォーカスインジケータを必ず表示（`outline` を消さない）

### スクリーンリーダー

- 画像には `alt` 属性を設定
- アイコンのみのボタンには `aria-label` を付与
- 視覚的に隠すテキストは `.sr-only` クラスを使用

| `.btn-primary` | 主要ボタン（オレンジ） |

| `.btn-lg` | 大きいボタン |
| `.btn-purchase` | 購入ボタン |
| `.btn-details` | 詳細ボタン（透明+ボーダー） |

| `.card` | 汎用カード |

| `.modal` | モーダルオーバーレイ |
| `.tag` | ステータス/カテゴリタグ |
| `.form-group` | フォーム入力グループ |
| `.section-title` | セクション見出し（20px, 下線付き） |

## 新しい画面を作るときのチェックリスト

- [ ] フォントサイズは 16px 以上か
- [ ] ボタンは十分な大きさ（44px 以上のタッチターゲット）か
- [ ] テキストと背景のコントラストは十分か
- [ ] 操作手順の説明やガイダンスがあるか
- [ ] 確認ダイアログが必要な操作に付いているか
- [ ] モバイル表示で崩れないか（768px ブレークポイント）
- [ ] キーボード操作が可能か
- [ ] ARIA 属性が適切に設定されているか
- [ ] 既存の CSS クラスを再利用しているか（新規作成は最小限に）
