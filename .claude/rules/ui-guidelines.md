# 高齢者向け UI 設計ガイドライン

本アプリは祖父母ユーザー（65歳以上を想定）が主要ターゲットの一つであるため、特に祖父母向け画面では高齢者に配慮した設計を徹底する。

## デザインシステム（温かみのあるモダン）

### カラーパレット

`src/app.css` の `:root` にCSS変数として定義済み。**色は必ず変数経由で使う**:

| 変数 | 用途 | 値 |
|------|------|------|
| `--primary` | 主要ボタン（白文字で4.5:1以上） | `#e0552f` |
| `--primary-soft` | 淡いオレンジ背景 | `#ffe8de` |
| `--secondary` | リンク・副次ボタン | `#1d6fa5` |
| `--accent-soft` | ガイド枠等の淡いイエロー | `#fff3d6` |
| `--text` | 本文 | `#3d3a36` |
| `--text-sub` | 補足文（これより薄い色は使わない） | `#6b645c` |
| `--bg` | クリーム背景 | `#fdf8f3` |
| `--danger` / `--success` | エラー / 成功 | `#c0392b` / `#2e7d4f` |

- 暖色系基調で親しみやすさを重視。テキストと背景のコントラスト比4.5:1以上を維持
- `#999` のような薄いグレー文字は禁止

### フォント

- "Noto Sans JP" + システムフォントフォールバック（外部フォント読み込みなし）
- 行間 `1.6` / 本文 **16px以上** / 見出し **20px以上** / ボタンラベル **16px以上**

### アイコン

- **絵文字**を使用（Font Awesome等の外部アイコンは使わない）
- テキストラベルと併用し、アイコンだけに意味を持たせない
- アイコンのみのボタンには `aria-label` を付与

## レイアウト原則

- カード: `.card`（白背景・角丸14px・柔らかい影・padding 24px）
- グリッド: `.card-grid` / `.photo-grid`（`auto-fill` + `minmax` でレスポンシブ）
- ブレークポイント **768px** でモバイル1カラム
- タッチターゲットは **44px×44px以上**（`.btn` は min-height 44px、`.btn-lg` は56px）

## 祖父母向け画面の設計指針

- メニューはシンプルに保つ。現在は マイページ / 写真を見る / ほしいもの / 記念品
  + ログアウト（フェーズ2で「記念品」が増えた）。これ以上は増やさない
- **ヘッダーに追加した導線はマイページのカードにも置く**。祖父母はヘッダーのリンクに
  気づきにくいため、主要機能はマイページから大きなボタン（`.btn-lg`）で辿れること
- 現在ページは `.active` クラスで明示
- 各ページに「← マイページに戻る」リンク（`.back-link`）を設置
- 主要操作は `.btn-lg`（18px / padding 15px 30px）
- 重要な操作（購入報告・削除）は `data-confirm` 属性で**確認ダイアログ**
  （`src/client.js` が処理）
- 各ページに操作手順のガイダンス（`.guide` + `<details>` で折りたたみ）
- 専門用語を避け、平易な日本語で記述（例:「購入したことを知らせる」）

## 写真閲覧

- グリッドは `minmax(200px, 1fr)`、写真全体が拡大ボタン（`.photo-view-btn`）
- モーダル拡大表示は `src/client.js` が制御: Escapeで閉じる・矢印キーで前後・
  背景クリックで閉じる・フォーカス戻し

## アクセシビリティ

- インタラクティブ要素に適切なARIA属性（モーダルは `role="dialog" aria-modal="true"`）
- キーボード操作: Tab移動 / Enter・Space / Escape / 矢印キー
- フォーカスインジケータを消さない（`:focus` は3pxアウトラインで統一済み）
- 画像には `alt` を設定（撮影日等の文脈を含める）

## 主要CSSクラス一覧（`src/app.css`）

| クラス | 用途 |
|--------|------|
| `.btn-primary` / `.btn-secondary` | 主要（オレンジ）/ 副次（ブルー）ボタン |
| `.btn-outline` / `.btn-danger` | 枠線ボタン / 危険操作 |
| `.btn-lg` | 大きいボタン（祖父母向け主要操作） |
| `.card` / `.card-grid` | カード / カードグリッド |
| `.photo-grid` / `.photo-item` | 写真グリッド |
| `.modal` | 写真拡大モーダル |
| `.item-list` | ほしいもの・通知のリスト |
| `.tag` (`-pending` `-accepted` `-purchased` `-expired`) | ステータスタグ |
| `.form-group` / `.form-errors` / `.form-hint` | フォーム |
| `.flash` (`-notice` `-alert`) | フラッシュメッセージ |
| `.guide` | 操作ガイダンス枠（`<details>`） |
| `.back-link` | 戻るリンク |
| `.nav-badge` | 未読件数バッジ |

## 新しい画面を作るときのチェックリスト

- [ ] フォントサイズは16px以上か
- [ ] ボタンは44px以上のタッチターゲットか
- [ ] 色はCSS変数経由か・コントラストは十分か
- [ ] 操作手順の説明（`.guide`）があるか
- [ ] 破壊的・重要操作に `data-confirm` が付いているか
- [ ] モバイル表示（768px以下）で崩れないか
- [ ] キーボード操作が可能か・フォーカスが見えるか
- [ ] 既存のCSSクラスを再利用しているか（新規作成は最小限に）
